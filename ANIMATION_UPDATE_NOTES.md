# Distinct 3D Animation Overhaul

This version replaces the previous generic Three.js geometry on About, Skills, Projects, Experience, and Contact with five visibly different animated vector scenes. Each scene has its own silhouette, layers, and motion design. The scenes are embedded locally in the HTML and do not require a Three.js CDN to render. Existing page content, navigation, and profile assets are retained.

For deployment, upload the updated five HTML files to the repository root. `index.html` is intentionally unchanged.
