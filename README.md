# Saktikanta Dhal — QA Automation Portfolio

## Files
- `index.html` — existing dark navy/cyan portfolio theme, responsive layouts, interactive section navigation, and contact links.
- `favicon.svg` — lightweight SD favicon matching the current brand colors.
- `404.html` — theme-matched not-found page for GitHub Pages.
- `Sakti_Dhal_Resume.pdf` — resume linked from the portfolio.

## Publish on GitHub Pages
1. Upload or replace these files at the root of `sakti-kd/My_portfolios` on the `main` branch.
2. Commit the changes.
3. In **Settings → Pages**, select `main` and `/(root)` if not already configured.
4. Wait for the deployment to complete, then open `https://sakti-kd.github.io/My_portfolios/`.

The site is static and requires no build step or additional JavaScript dependencies. Google Fonts are optional; system font fallbacks are included. A personal LinkedIn profile URL was not supplied, so the generic LinkedIn homepage link was removed rather than pretending it was the user's profile.
