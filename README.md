# Saktikanta Dhal — QA Automation Portfolio

A responsive, dark-premium portfolio for a QA Automation Engineer, built with plain HTML, CSS, and JavaScript. Includes lightweight motion effects, scroll-reveal sections, a reading-progress bar, responsive navigation, and an illustrative terminal panel.

## Files
- `index.html` — portfolio website
- `Sakti_Dhal_Resume.pdf` — resume used by the download links

## Before publishing
- Replace the generic LinkedIn and GitHub links in `index.html` with your actual profile URLs.
- Check the content for accuracy and ensure no confidential client information, credentials, or internal application details are published.
- Keep `Sakti_Dhal_Resume.pdf` in the repository root, next to `index.html`, so the resume download works.

## Update the existing GitHub Pages site
1. Open your `My_portfolios` GitHub repository.
2. Open `index.html`, click the pencil (Edit) icon, select all old code, and replace it with the new `index.html` content from this package.
3. Commit the changes to the `main` branch.
4. Upload `Sakti_Dhal_Resume.pdf` to the repository root if it is not already there. If prompted that the file already exists, do not create a duplicate.
5. Confirm **Settings → Pages → Deploy from a branch → `main` → `/(root)`**.
6. Wait a few minutes, then refresh `https://sakti-kd.github.io/My_portfolios/`.

## Local preview
Open `index.html` in a modern browser. Google Fonts are optional; system fonts will be used if they cannot load.

The terminal visual is explicitly marked as a demo, not a live test run. The current Agentic AI project description reflects using agents and validating/debugging generated scripts; it does not claim the agents were developed by the portfolio owner.
