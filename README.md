# Saktikanta Dhal — Portfolio

A clean, responsive portfolio website for a QA Automation Engineer. Built using plain HTML, CSS and JavaScript.

## Before publishing
- Replace the generic LinkedIn and GitHub URLs in `index.html` with your actual profile links.
- Review the project descriptions for accuracy and ensure no confidential client details are included.
- Resume download expects `assets/Sakti_Dhal_Resume.pdf`.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public repository and upload `index.html`, `README.md`, and the `assets` folder.
2. Open repository Settings → Pages.
3. Choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Wait for the published URL to appear in Pages settings.

The Agentic AI section describes the user's role accurately as using agents and validating/debugging their generated output; it does not claim that the user developed the agents.
