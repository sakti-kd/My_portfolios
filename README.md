# Saktikanta Dhal — Interactive QA Automation Portfolio

## Files
- `index.html` — responsive portfolio with animated 3D-inspired globe, floating skill panels, animated section tabs, project/skills/experience panels, and contact links.
- `Sakti_Dhal_Resume.pdf` — resume PDF linked from the site.

## Publish on GitHub Pages
1. Upload `index.html`, `README.md`, and `Sakti_Dhal_Resume.pdf` to the root of `sakti-kd/My_portfolios` on the `main` branch.
2. Commit the upload to `main`.
3. In Settings → Pages, use `main` and `/(root)` if not already configured.
4. Open https://sakti-kd.github.io/My_portfolios/ after deployment.

The website uses CSS animations and lightweight DOM interactions; it does not require a build step or JavaScript framework. Google Fonts are loaded from Google Fonts; if unavailable, system fonts are used. Replace the placeholder LinkedIn URL with your personal profile URL when ready.
